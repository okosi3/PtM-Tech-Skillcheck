This file describes the PTM SkillCheck additions:

World Outliner:
    Tavern_Guard_000
        Located: front of Building_Tavern 
        Dialogue: PTM_Tavern_Guard
        Stats: HalfElf_Melee
        Equipment: PTM_Tavern_Guard
        Has a pickpocketable key (PTM_TAVERN_KEY) that opens Tavern_Door_Main
    Tavern_Button_EventTrigger
        Located: behind Building_Tavern
        Connected to PTM_Tavern_Door_EventTrigger_Script
    Tavern_Door_Button 
        Located: behind Building_Tavern
        Connected to PTM_Tavern_Door_Script
    PTM_TAVERN_KEY
        Located: front of Building_Tavern (Tavern_Guard_000's items)
        Key ID: PTM_Tavern_Main_Door

Dialogue: 
    PTM_Tavern_Guard 
        Designed for Tavern_Guard_000
        Sets 3 flags (all unique)
            PTM_Tavern_Guard_Upset (dialog): flag set when player fails insight skill check, npc will no longer continue dialog
            PTM_Tavern_Guard_Quest (dialog): flag set when player passes insight skill check but did not progress far enough to accept quest 
            PTM_Tavern_Guard_AcceptQuest (global): flag set when player accepts quest (this flag also opens/unlocks Tavern_Door_Main and disables Tavern_Door_Button)
    
Scripts:
    PTM_Tavern_Door_Script
        KB: 
            locks/unlocks and open/close the door based on Tavern_Door_Button interaction
            opens and unlocks door if the flag PTM_Tavern_Guard_AcceptQuest is set
    PTM_Tavern_Door_EventTrigger_Script
        KB: 
            if the flag PTM_Tavern_Guard_AcceptQuest is set, disables perception check and button interaction to prevent softlocking
            rolls a perception check when the player enters eventtrigger and prevents future entertriggers for that player (using tag PTM_PERCEPTIONCHECK_TAVERNBUTTON)
            if PTM_TavernButtonPerceptionCheck (perception check) is successful, sets player interaction with Tavern_Door_Button to true
